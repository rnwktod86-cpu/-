# 예약접수 / 자료등록 공용 프로그램

첨부된 `해운대2` 엑셀 양식(17개 컬럼)을 여러 명이 함께 쓰는 웹 프로그램으로 만든 것입니다.

## 실행
Node.js 22.13 이상 필요 (추가 설치 패키지 없음).

    npm start

- 본인 PC: http://localhost:3000
- 같은 네트워크의 다른 사람: http://(서버 PC의 IP):3000
- 포트 변경: `PORT=8080 npm start`, DB 위치 변경: `DB_FILE=/경로/reservations.db`

## 바탕화면 아이콘
`바탕화면_아이콘_만들기.bat`(Windows) 또는 `바탕화면_아이콘_만들기.command`(Mac/Linux)를 한 번 실행하면 바탕화면에 `예약접수` 아이콘이 생깁니다.

## 기능
- 예약 등록 / 수정 / 삭제 (예약번호 미입력 시 `YYYYMMDD-001` 형식으로 자동 생성)
- 전체 검색, 예약일 기간 필터, 15초마다 자동 새로고침(다른 사람이 입력한 내용 반영)
- 엑셀용 CSV 내보내기 (한글 깨짐 방지 BOM 포함)
- 최종 수정자·수정시각 기록

데이터는 `data/reservations.db`(SQLite)에 저장되므로 이 파일만 백업하면 됩니다.
인증 기능은 없으므로 사내망에서만 사용하세요.
